The shortest case, E12, used 228 input tokens and 5934 ms; the longest case, E11, used 274 input tokens and 5091 ms. Input tokens rose with document length, but latency did not: E12 was slower even though it was shorter, because it was the first call and paid model-load cost. A short document is therefore a poor way to estimate model workload; you have to measure token counts and latency on longer cases rather than scaling from one small example.
